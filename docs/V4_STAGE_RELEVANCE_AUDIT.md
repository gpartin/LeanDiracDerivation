# V4 stage relevance audit

## Scope

V4 claims that one localized native `Psi`--`chi` carrier realizes the free
Dirac electron at rest and while moving.  A test belongs in the release gate
only when failure would contradict that claim.  Stronger diagnostics may be
retained, but they may not silently become mandatory physics requirements.

## Retired overrequirements

The following interpretations are rejected:

1. every arbitrary full-lattice perturbation must be neutrally stable;
2. the four-component readout must have exactly zero finite-lattice remainder;
3. an electron must be a rigid snapshot between lattice sites;
4. one cell must be crossed in one numerical timestep;
5. both cubical copies must be collapsed into one or behave identically by
   assumption;
6. Lean can turn a finite numerical endurance run into a mathematical proof.

These are not excuses to ignore a failure.  A full-spectrum mode remains a
real blocker when the admitted carrier preparation or unrestricted native
evolution excites it.

## V4-002 reachability result

`v4_002_reachable_sector_audit.py` uses the exact existing packet lift rather
than a hand-selected stable subspace.  Its inputs cover both cubical copies,
both momentum signs, all three axes, a held diagonal, both committed layers,
the native surroundings, and the independently evolved C19/centered-time
Dirac comparator.  The native recurrence is unrestricted.

The reported complete-frame growing response is reached by those physical
launches.  Therefore the old ambient-spectrum wording was overbroad, but the
underlying V4-002 failure is relevant to the claimed electron.  V4-002 remains
open on the narrower and correct gate.
