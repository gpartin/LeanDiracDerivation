# V3.2 citation-language audit

This audit records the English-accessibility check requested for the V3.2
release bibliography. It changes attribution metadata only; it does not change
the Lean definitions, proofs, action, or claims.

| Earlier entry | V3.2 English-accessible treatment |
| --- | --- |
| Iwanenko--Landau, German original | Historical lineage reported through Teixeira's English review and Becher--Joos's English lattice treatment |
| Kähler, German original | Explicitly credited as the primary source but marked not directly consulted; its construction is documented through Vargas, Teixeira, and Becher--Joos |
| Noether, German original | Tavel's published English translation, “Invariant Variation Problems” (1971) |
| Lubański, French original | Kryuchkov, Lanfear, and Suslov's English Pauli--Lubański treatment (2016) |
| Schrödinger, German original | *Collected Papers on Wave Mechanics*, English translation by Shearer and Deans (1928) |

No verified English edition of Kähler's original was located during this
audit. Vargas's peer-reviewed 2008 English treatment explicitly reports that
Kähler's work had not been translated. Kähler remains cited as the primary
historical source, while the documentation marks the original as not directly
consulted and relies on Vargas, Teixeira, and Becher--Joos for the substantive
English account. The Iwanenko--Landau original is not represented as a source
read directly.
