DIRAC-027 PASS: spin one half is now a frame-independent result

Earlier stages showed the cube carrier changes sign after one full turn and
returns after two. DIRAC-027 asks the harder relativistic question: does that
same spin remain one half for a moving observer?

Lean combined the rotations already derived from cube geometry with the
boosts derived in DIRAC-026. It built the standard relativistic spin object
and squared it. The result was

    W^2 = -(3/4) m^2

The factor `3/4` is exactly `s(s+1)` for `s = 1/2`. It was not entered as a
spin label or fitted constant; it fell out when the inherited cube operators
were multiplied and simplified. Substituting the independently proved
boosted mass shell leaves the same value at every rapidity and along every
axis.

So the chain now has both pictures of spin one half: the cube's two-turn
rotation behavior and the frame-independent relativistic invariant. They
come from the same four-component sector.
