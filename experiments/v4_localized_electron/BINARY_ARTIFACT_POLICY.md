# V4 binary artifact policy

The committed V4 checkpoint contains the executable Python sources, reports,
CSV tables, and JSON evidence/metrics.  Rebuildable `.npz` matrix caches and
temporary `.npy` arrays are intentionally not committed: the current local
research set is about 1.34 GiB and includes a 137 MiB file, which exceeds
GitHub's ordinary per-file limit.

Those arrays remain in the research worktree and are regenerated by the
adjacent scripts.  A binary cache is not proof evidence by itself; the compact
JSON result and the source that produced it are the review boundary.  Any
future binary that is essential and not reproducible must be archived through
an explicit release/LFS artifact process with its hash recorded here before it
is relied upon by a published claim.
